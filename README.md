# LLM Exercises

A practical collection of small, focused exercises for learning and applying large language model workflows, including prompting, evaluation, tool use, and lightweight applications.

## Goals

- Build intuition through short, repeatable tasks
- Keep examples minimal, clear, and easy to run
- Encourage good habits: testing, evaluation, reproducibility, and documentation

## Repository Structure

- `01_ollama/`  
  Using Local LLM

- `02_openaAI/`  
  ChatGPT and all

- `09_AgenticAI/`  
  Agentic AI Simple Demo Project

- `sample_project/`  
  Sample LLM Project
